# KDD Cup 2026 DataAgent-Bench Starter Kit

This repository contains starter kits for different competition phases.

| Directory | Use case |
| --- | --- |
| `PHASE_1/` | Phase 1 starter kit. |
| `PHASE_2/` | Phase 2 starter kit with the Phase 2 demo data format. |

Start from the directory that matches your phase:

```bash
cd PHASE_1
# or
cd PHASE_2
```

Each phase directory contains its own README, configuration files, source code, and run instructions.
